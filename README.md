# 日历故事

日历故事是一个本地运行的中文日历与家庭生活网页应用。输入一个公历日期，页面会组合日历信息、历史文化内容、天气、生活建议和按儿童年龄阶段生成的育儿提示。

应用运行在自己的电脑上，默认只监听 `127.0.0.1:5091`。本仓库公开的是源代码；GitHub 不会托管或自动运行这个 Flask 应用。

## 功能一览

- **日期查询**：查询指定日期，也可一键回到今天。接受完整日期；输入月日时按当前年份查询。
- **公历、农历和节气**：显示星期、年周、季度、月相、农历、干支、生肖和节气。农历计算使用 `sxtwl`；节日与节气补充表保存在 `config_traditional_and_solar_1965_2030.ini`。
- **传统日历信息**：显示宜、忌、冲煞、吉神、凶神和吉时。传统黄历内容用于文化参考。
- **节日、历史和人物**：按查询日期展示节日纪念日、中国与世界历史事件，以及相关人物资料。
- **文化与生活方式**：提供中英文名言、作品、问候语、饮食、生活和穿衣建议。
- **天气**：选择配置的城市查看天气。数据通过 Open-Meteo 获取，不需要 API 密钥。
- **养生与三餐**：按季节和节气生成日常养生、运动、作息、情绪及三餐建议；模型不可用时使用本地兜底文本。
- **查询历史与缓存**：历史下拉框可回看已查询日期。默认读取本地缓存；勾选“强制刷新”会重新生成并更新缓存。

## 育儿提示

页面的“卡尔·威特今日育儿提示”模块根据用户选择的儿童生日，计算查询日的年龄，并生成适龄的亲子任务。生日栏默认留空，不再预填任何儿童生日。

程序把年龄分为四个大阶段：0–2 岁、2–6 岁、6–12 岁和 12 岁以上；每个阶段还有更细的年龄区间和关注重点。例如，幼儿阶段侧重感官、动作、语言和亲子互动；学龄阶段逐步加入规则、阅读、计划、思考与复盘。

建议包含当日主题、主任务、备选任务、进阶任务、观察点和复盘问题。活动时长按年龄调整：2 岁以下约 8–12 分钟，2–6 岁约 12–20 分钟，6–12 岁约 20–30 分钟，12 岁以上约 25–40 分钟。程序结合本地活动模板和最近 7 天的提示，尽量避免重复；DeepSeek 服务不可用时会退回本地模板。生成规则排除体罚、羞辱、恐吓等不当建议。

**儿童生日隐私**：生日栏留空时，不生成个性化育儿提示，也不会传送儿童生日。填写生日后，精确生日只在本机用于年龄计算并保存在本机 `cache/` 中；发送给配置的 DeepSeek 兼容服务的育儿提示请求包含查询日期、年龄阶段和任务上下文，不包含完整生日或精确到天的年龄。基础日历内容也会把查询日期和生成提示发送到配置的模型服务。请先阅读并接受所选服务商的数据处理规则，再输入儿童生日。

这些内容是程序模板与 AI 生成的日常参考，不是儿童发育评估、医疗意见或专业个案指导。请结合孩子状态判断，不适用的建议不要执行。

## 运行环境与安装

需要 Python 3.9 或更新版本，以及可访问 DeepSeek 兼容 API 和 Open-Meteo 的网络连接。页面样式使用 Bootstrap CDN，首次打开页面也需要网络。

在 Windows PowerShell 中进入项目目录后执行：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item config.example.ini config.ini
```

编辑本地 `config.ini`，把 `api_key` 替换成你自己的 DeepSeek API 密钥。不要把 `config.ini`、`.env` 或密钥粘贴到公开仓库、截图和问题报告中。应用启动时要求 `config.ini` 存在；没有有效密钥时，依赖模型的日历生成无法正常工作。

启动方式一：

```powershell
python app.py
```

启动方式二：双击 `CalendarStory.bat`。该脚本使用 Waitress，并与 `python app.py` 一样只监听本机。

然后在本机浏览器打开 <http://127.0.0.1:5091>。如要让局域网其他设备访问，请先理解网络暴露范围，再自行把监听地址改为可信网络接口；不要直接把调试服务器暴露到公网。

## 配置

`config.example.ini` 是不含密钥的模板。复制为本机的 `config.ini` 后，可配置：

- DeepSeek 兼容 API 地址、密钥、模型名称、温度、输出长度和重试策略。
- Open-Meteo 天气接口、时区、默认城市和城市坐标。

密钥只保存在未跟踪的 `config.ini`。本项目的 `.gitignore` 会忽略本机配置、备份、缓存、日志和 Python 运行文件。缓存目录可能包含查询结果、精确儿童生日和育儿建议，不要公开其中的内容。

## 内容与隐私说明

历史事件、人物描述、名言、生活建议和育儿提示可能由 AI 生成，准确性不作保证。传统黄历仅为文化信息。养生内容不代替医疗意见，育儿内容不代替专业评估。

除非用户主动输入儿童生日，应用不会使用预设生日。查询结果和育儿提示缓存保存在本机 `cache/`，可停止应用后按需删除该目录；删除后，旧日期需要重新生成。
